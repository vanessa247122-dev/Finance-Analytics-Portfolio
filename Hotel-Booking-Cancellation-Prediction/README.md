A predictive analytics project focused on identifying hotel reservations that are likely to be cancelled before the scheduled stay. The model uses historical booking data and the is_cancelled target variable to identify patterns associated with cancellations.

Tools & Techniques
RapidMiner
Data Cleaning & Preparation
Decision Trees
Parameter Optimization
Cross-Validation
Model Evaluation
Confusion Matrix
Performance Testing
Data Visualization

Project Objective
The goal of the model is to predict whether a hotel booking will be cancelled before it happens. By analyzing patterns in historical booking data, the model attempts to identify reservations that are at higher risk of cancellation, allowing hotels to potentially take action before the scheduled stay.
