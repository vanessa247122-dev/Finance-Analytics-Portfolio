A two-person predictive analytics project using Python to develop a regression model for predicting house prices based on selected property features.

Tools & Techniques:
Python,
Regression Modeling,
Data Cleaning & Preparation,
Exploratory Data Analysis,
Data Visualization,
Model Evaluation,

Project Objective:
The goal of the project was to develop a regression model that could predict house prices based on relevant property features. The analysis involved preparing the data, exploring relationships between variables, developing the regression model, and evaluating its performance.

Files:
Python Notebook — Jupyter Notebook containing the data preparation, analysis, regression modeling, visualizations, and model evaluation.
